# Proyek referensi

`Heart_Rate Monitor.pdsprj` adalah proyek simulasi Proteus asli dari:

- Repo: <https://github.com/Eemayas/Heart_Beat_Simulation_Proteus>
- Lisensi: MIT (lihat `LICENSE` di folder ini)

Proyek ini disimpan apa adanya untuk pembanding. Untuk simulasi yang sudah
disesuaikan (sudah memakai sketch dan HEX implementasi ini), buka
`../detak_jantung.pdsprj`.

Library Proteus yang dibutuhkan sudah dipasang di komputer ini
(Proteus 8 dan Proteus 9). Kalau proyek dipindah ke komputer lain, install
library dari `../libraries/` terlebih dahulu.
